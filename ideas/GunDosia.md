# Идея пет-проекта: Мод-менеджер для автосимуляторов

- **Описание:** Программа для удобной установки и управления модификациями (машинами, картами) для BeamNG.drive и других симуляторов.
- **Стек технологий:** Python / JS
- **Функционал:** Автоматическая распаковка zip-архивов в нужные папки игры и проверка конфликтов.
