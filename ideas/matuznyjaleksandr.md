# Идея проекта: matuznyjaleksandr

## Название проекта
Трекер учебных задач и дедлайнов

## Описание
Приложение для студентов, которое помогает отслеживать домашние задания, проекты и экзамены. Позволяет расставлять приоритеты и получать напоминания.

## Технологии
- Python (Django или Flask)
- HTML, CSS, JavaScript
- База данных SQLite

## Цель
Закрепить навыки работы с фреймворками и базами данных, создав полезный инструмент для учёбы.
